# Ciencia-de-Datos
Repositorio para guardar los informes de la asignatura "Ciencia de Datos"

Etapa 1:

- Planteamiento del problema como función de costo empresarial, balanceando costo de deserción de clientes vs. costo de compensaciones
- Análisis exploratorio completo (univariado, bivariado y multivariado) sobre dataset de vuelos con variables climáticas, operativas y de demanda
- Priorización de falsos negativos como métrica clave con justificación de impacto económico real
- Evaluación y comparación de cuatro modelos de clasificación: KNN, árboles de decisión, análisis discriminante y regresión logística
- Verificación de supuestos estadísticos en cada modelo (normalidad, homocedasticidad, multicolinealidad, autocorrelación)
- Implementación en Python y SPSS Modeler
